How It Works

Three steps, with clear user control.

The flow is intentionally simple so users understand what is being measured, why permission is needed, and how completion is decided.

1

Choose apps

Users explicitly select which apps to monitor using Apple’s system picker.

2

Set a deadline

Set a daily deadline and reminder schedule for each task.

3

Complete automatically

If the selected app reaches the daily usage threshold, the task is marked as completed automatically.

Privacy & permissions

Built with privacy in mind

This product is intended for personal self-management and daily accountability. It is not a monitoring or surveillance tool.

  • The app uses Apple's Screen Time APIs.
  • Users explicitly grant permission before app activity can be monitored.
  • Users explicitly choose which apps to include.
  • The app does not access content inside other apps.
  • The app does not detect taps, text, messages, or screen content.
  • The app only uses usage thresholds to determine task completion.

Review note

The monitored scope is limited to user-selected apps and daily completion logic. No in-app content inspection is performed.

FAQ

Clear answers for review and user trust.

Does the app read content inside other apps?

No. It only relies on Apple’s Screen Time APIs and usage thresholds for user-selected apps.

Does the app monitor all apps automatically?

No. Users explicitly choose which apps they want to include.

Can the app detect buttons or actions inside another app?

No. It does not inspect in-app content or user actions.

Who is this app for?

It is designed for people who want simple reminders and daily accountability for app-based habits.
